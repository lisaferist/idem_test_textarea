Тестовое задание
Нужно реализовать поле textarea, в котором при вводе @ 
появляется выпадающий список пользователей.

Требования к функционалу:
При вводе @ + текст сразу показывается список пользователей 
(фильтр по ФИО / username).

Позиционирование дропдауна, со списком подходящих пользователей, 
рядом с курсором(не просто снизу инпута)

После выбора — вставка @username в текущую позицию курсора 
и продолжение ввода.

Поддержка нескольких упоминаний в одном тексте.

Список должен скрываться при потере фокуса, esc, клик вне 
элемента
